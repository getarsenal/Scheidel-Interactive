# shots/

Screenshots for project detail pages, referenced by the `screenshots:[...]` field in the
`PROJECTS` array in `index.html`.

- Default tiles render portrait (9:16). Append `::wide` to a path for a landscape (16:9)
  shot, e.g. `"shots/arsenal-1.png::wide"`.
- Suggested naming: `shots/<slug>-1.png`, `shots/<slug>-2.png`, …
- Click-to-zoom (lightbox) works automatically.

Until a project has screenshots, the detail page shows "Screens coming soon" placeholders.
