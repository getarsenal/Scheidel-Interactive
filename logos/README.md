# logos/

Per-project logo art referenced by the `logo:` field in the `PROJECTS` array in
`index.html`. PNG or SVG. Square art works best (rendered into a rounded tile).

Expected paths (rename the files **or** the `logo:` values so they match):

| Project         | Expected file                  |
|-----------------|--------------------------------|
| ARSENAL         | `logos/arsenal.svg`            |
| FIREBASE        | `logos/firebase.svg`           |
| Mission Tracker | `logos/mission-tracker.svg`    |
| Leave Her Johnny| `logos/leave-her-johnny.png`   |
| Colony Commander| _(letter fallback until added)_|
| Range 1         | _(letter fallback until added)_|

Any missing or broken logo automatically falls back to a generated letter tile, so the
site never renders broken — drop art in here when it's ready.
